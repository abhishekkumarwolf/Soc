# 📌 Overview

soc is a modern cybersecurity monitoring platform designed to simulate a Security Operations Center (SOC) environment. It provides real-time event streaming, malware scanning, alert management, traffic analysis, and security analytics through an interactive dashboard.

The project combines scalable backend architecture with a visually immersive frontend experience to create a practical cybersecurity monitoring solution.

---

# ✨ Features

## 🔥 Real-Time Threat Monitoring
- Live event streaming using WebSockets
- Real-time alert generation
- Continuous security event tracking

## 🛡️ Antivirus & Malware Detection
- Malware scanning system
- Threat analysis services
- Security event correlation

## 📊 Interactive Security Dashboard
- Live security metrics
- System performance statistics
- Threat visualization panels

## 🌐 Network Traffic Analysis
- Network activity monitoring
- Traffic visualization
- Topology mapping

## ⚡ Modern UI Experience
- Matrix-style animated background
- Interactive analytics dashboard
- Responsive SOC-inspired interface
